Getting started

Writing with Lasso in a few minutes

  1. Install and allow

    Open Lasso and give it Accessibility permission, so it can read the text before your caret and insert what you accept.

  2. Add a folder

    From the menu bar, add the folder you work from, such as this month’s close or one client’s files. Lasso indexes it on your Mac.

  3. Start typing

    Write in any app. When a word matches, the card appears; Tab inserts. ⌥Tab chooses where suggestions come from.
