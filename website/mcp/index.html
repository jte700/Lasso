3D model · STEP assemblyRight with all three

“In Engineering/Flange assembly.step, what is the angle in degrees between the z axis of Sensor:1 and the z axis of Bolt:3?”

Why it needs the whole assembly. Each part's axes are stored in its own coordinates. The sensor is tilted and the bolts are turned around a bolt circle, so the angle only exists once both placements are composed through the assembly.

Answer · Lasso, in one call
30°
"Bolt:3" from "Sensor:1": 48.2183 mm apart; … axes x 90°, y 90°, z 30° apart (assembly frame: "Sensor:1" at [90, 30, 20], "Bolt:3" at [50, 55, 10])

Uploading the reports was cheapest here and got the most right. On short and mid-size documents, attaching them is hard to beat; Lasso's lead grows with the size of the file.

When to use Lasso, and when to attach the file

Lasso against uploading the files with the question.

Large files and 3D modelsUploads send the whole file on every call. Lasso used 99% fewer tokens on the 5,000-row workbook, 74% fewer on the 40-page PDF and 59% fewer on the STEP assemblies, and was never less accurate.
A page or two, a small sheetAttaching costs less than one tool call: two 1–2-page PDF tasks took 755 tokens uploaded against 6,875 with Lasso. On small sheets Lasso still got more right (7 of 7 against 4 of 7).
Mid-size reportsOn the fresh 8–9-page set, uploading got 14 of 18 right in 60.5K tokens; Lasso 12 of 18 in 69.4K.

Connect an agent

One tool, on your machine

Lasso's MCP server reads the library the Lasso app keeps. Add your folders in Lasso first, then point your agent at it and name the folders it may read.

Claude Desktop and other MCP hosts

{
  "mcpServers": {
    "lasso": {
      "command": "/Applications/Lasso.app/Contents/MacOS/node",
      "args": [
        "/Applications/Lasso.app/Contents/Resources/app/src/agent/cli.js",
        "mcp", "--scope", "Finance"
      ]
    }
  }
}

Claude Code

claude mcp add lasso -- \
  /Applications/Lasso.app/Contents/MacOS/node \
  /Applications/Lasso.app/Contents/Resources/app/src/agent/cli.js \
  mcp --scope Finance
  • An agent sees only the folders you name with --scope: a folder's name as Lasso shows it, its path, or "*" for every enabled folder.
  • Credential files and anything you've excluded from Lasso's suggestions stay out.
  • It runs locally over stdio: no port, no account, no API key. The agent gets only the evidence it asks for.
Method

How these were measured

Live runs. OpenAI's gpt-5.4-mini at low reasoning effort, through the Responses API, choosing its own steps. In each task it had either ordinary file tools (read, search and list, with PDF, Word and Excel files converted to text), those tools plus Lasso's one tool, or no tools and the files attached to the question. Tokens are the provider's usage records: every input and output token of every call in the task.

Tasks. Generated libraries whose answers are known: code and documents for lookups, 3D models, workbooks and reports for the rest. Answers are graded against the facts the files were written with, including whether conflicting sources and caveats were reported.

Runs. Lookups: two runs per arm, October 2026. Kinds of file: one run on 30 October ($1.01). Mid-size reports: one run on 31 October ($0.47). The same task can vary a lot between runs, so small single-task differences are noise; the differences on large files and 3D models are not. The lookups were measured with an earlier version of the tool; the changes since kept every lookup answer right offline.

The benchmark code, every task and the full reports are in the repository: docs/agent/README.md.
