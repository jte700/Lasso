    What Lasso is

    Lasso is a local-first source library1README.md › Lasso“A local-first source library and writing assistant with versioned evidence.”
    pinned · aaff5fc     and writing assistant. It connects the information you use while writing to the files it came from.

    Most of writing is looking things up: which folder, which version, which tab, which page. Lasso does the sifting. Ask for the number, the clause or the figure and it retrieves the exact document and location it lives in.

    Point it at a project folder. It indexes documents, spreadsheets, notebooks, references and drawings, down to the exact cell, passage or IfcSpace, and keeps an immutable snapshot2History storeSQLite plus content-addressed file snapshots. Project files stay in their original directory.
    pinned · aaff5fc     of every version.

    As you type, it suggests values, citations and sentence continuations from your own evidence. Press Tab and the link comes with it: source object, location, version.

    When a file changes, Lasso shows you which sentences depended on it3Review changesInspect previous and current values, affected document references and indexing failures before applying updates.
    pinned · aaff5fc    , what the old value was, and what it is now.

    No language model. No API key. Retrieval, ranking, extraction and provenance all run on your machine. Ambiguous measurements aren’t guessed4docs/design-source-indexing.mdLasso does not infer missing BIM quantities or reconstruct rooms from arbitrary drawing geometry.
    pinned · aaff5fc    . If the evidence isn’t there, neither is the answer.

    Retrieval first

    Stop sifting. Start finding.

    Ask for the number, the clause or the figure. Lasso ranks every indexed document and takes you to the exact cell, passage or object it lives in, not just a file it might be in.

    The exact locationCell D12, clause 12.3, IfcSpace Schlafzimmer. Not “somewhere in this PDF”.
    The right versionDrafts and superseded files are ranked and labelled, so you don’t cite the wrong one.
    No evidence, no answerIf nothing in your project supports it, Lasso says so instead of guessing.

    Write with evidence

    Autocomplete that shows its work.

    Suggestions come from your indexed project, not from a model. Right inside the suggestion box, Lasso previews the source itself (the floor plan, the sheet, the paper, the clause) so you can confirm it’s the right one before you press Tab. Later, click any highlight to check it again.

    Supported sources

    From prose to polylines.

    Support varies by format and content. Files stay in history even when structured extraction isn’t available.

    .md .txtPassages, source-backed continuations and claims
    .csv .tsv .xlsxTables, rows, cells, values and variable definitions
    .docx .pdfExtractable text and metadata; explicit drawing annotations in PDFs
    .ipynb .json codeCode locations, structured values and notebook cells
    .bib .ris .enw .nbibReference records with author, year, title, DOI and PMID
    .ifcElement quantities and typed properties, with entity identity and units
    .dxfArea and perimeter of supported closed model-space polylines
    .landxmlParcel areas, alignment and pipe lengths, diameters and elevations

    Scanned PDFs need OCR first. DWG, RVT and DGN need an export to IFC, DXF or LandXML. Lasso does not infer missing quantities.
